# 任务 2-1 · 认识动力装置

[直流电机](index.html)和[柴油机](diesel.html)使用各自原有的三维模型与渲染程序。可用同一排标签进入电机或切换单缸、四缸。播放或单步观察，点击部件名称查看位置和作用。

课堂重点是区分电机的固定部件和转动部件，观察活塞、连杆与曲轴的运动，以及四个气缸怎样依次做功。三种装置均为原创教学剖面模型。

右侧保留实际模型交互：电机可切换正反向接线，暂停后比较电流、受力标记，再单步观察输出轴转向；柴油机可点选进气、压缩、做功、排气，或拖动滑条定位曲轴。四缸可选择观察气缸，冲程按钮按所选气缸定位。拆解期间禁用冲程操作，合成后恢复；复位恢复原模型状态。

两个页面采用一致的紧凑工具栏和观察侧栏。电机源模板在 `src/motor.html`，柴油机源文件在 `diesel-source/`，入门布局在 `assets/power-lesson.js` 和 `assets/power-lesson.css`。运行 `node scripts/build.mjs 2-1` 更新入口。
