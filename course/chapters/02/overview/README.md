# 第二章 · 动力与工作机构

[打开第二章入口](index.html)。按动力来源、动力传递和施工动作组织三个任务。

| 任务 | 入口与观察重点 |
| --- | --- |
| 2-1 动力装置的基本原理 | [直流电机](../tasks/2-1/index.html)与[柴油机](../tasks/2-1/diesel.html)，观察转子和活塞怎样带动轴转动 |
| 2-2 动力的传递与变换 | [动力传动](../tasks/2-2/index.html)，观察机械、液压与气压传动 |
| 2-3 工作机构与施工动作 | [工作机构](../tasks/2-3/index.html)及[四杆扩展](../tasks/2-3/fourbar.html)，观察动臂、升降与夹持 |

任务 2-1 保留原版电机与柴油机三维页面，使用一致的观察布局。各任务入口由课程清单提供。

在仓库根目录运行 `node scripts/build.mjs 2` 更新第二章，运行 `npm run verify` 构建、校验并打包。
