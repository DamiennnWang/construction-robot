# 第二章 · 动力与工作机构

[打开第二章入口](index.html)。一条动力链：动力从哪里来（2-1）→ 传过去以后变了多少（2-2）→ 最后变成什么样的动作（2-3）。

| 任务 | 工位 |
| --- | --- |
| [2-1 动力装置的基本原理](../tasks/2-1/index.html) | 直流电机（含亲手组装）· 柴油机（含拆装、装进挖掘机） |
| [2-2 动力的传递与变换](../tasks/2-2/index.html) | 齿轮/皮带/链条 · 液压缸 · 气缸 —— 只管快慢、方向、力的大小 |
| [2-3 工作机构与施工动作](../tasks/2-3/index.html) | 液压缸 · 动臂（伸缩变转动）· 丝杠 · 升降台（转动变直线）—— 只管运动形式怎样改变 |

页面按 [课程页面设计规范](../../../设计规范.md) 组织：三维模型沿用原版，右侧面板是自由设计的控件和“试一试”挑战。

在仓库根目录运行 `node scripts/build.mjs 2` 更新第二章，运行 `npm run verify` 构建、校验并打包。
