LEARNING ROUTE / 05

先准备现场，再理解工序接续。

  1. 加工与识读：完成调直、切断、弯曲订单，再巡查楼面、操作检查工具、划分作业区域。
  2. 绑扎与复核：对准交点、保持就位，观察送丝与扭结；再停稳隔离、检查样例，处理并重新复核疑点。
  3. 混凝土工序：阅读泵送、布料、振捣、粗平、精平与抹光的分工，理解标高参照与调平反馈。

5-1 与 5-2 为独立交互课堂，不自动传递作业记录；5-3 为工序导读，混凝土交互演示尚未制作。
